La CAH de Ward avec R

Classification ascendante hiérarchique · R Lab — Antoine Géré

Ce TD comporte deux exercices à réaliser avec R sous RStudio, pour construire une typologie par classification ascendante hiérarchique (CAH) avec le critère de Ward :

  • Exercice 1 (guidé) : typologie de 15 exploitations d'un bassin cotonnier soudano-sahélien. Tout le code R est fourni ; des encadrés Lecture expliquent les sorties et des lignes ✓ Contrôle permettent de vérifier ses résultats.
  • Exercice 2 (en autonomie) : typologie de 18 exploitations maraîchères péri-urbaines. Aucun code n'est fourni : on écrit son propre script et l'on justifie chaque choix.

Les jeux de données sont fournis dans les fichiers Excel data_stat-0113.xlsx et data_stat-0114.xlsx (feuille donnees ; la feuille description rappelle le sens et l'unité de chaque colonne), à placer dans le dossier data_raw de votre projet RStudio. On utilise les packages readxl et FactoMineR.

Ces exercices entraînent à construire une typologie comme on le fera en stage ou en mémoire : les choix (centrer-réduire, critère de Ward, nombre de classes) ; la lecture des sorties de R (dendrogramme, hauteurs de fusion, part d'inertie expliquée, valeurs-tests) ; l'interprétation (caractériser et nommer les classes, en tirer des conseils différenciés).

Le principe en deux lignes

On cherche des groupes d'individus homogènes (qui se ressemblent à l'intérieur d'une classe) et bien séparés (différents d'une classe à l'autre). L'inertie totale se décompose en inertie intra-classe et inertie inter-classe : une bonne partition a une inertie inter-classe forte, c'est-à-dire un rapport \(R^2 = \dfrac{\text{inertie inter}}{\text{inertie totale}}\) proche de \(1\).

Exercice 1 (guidé) — typologie d'exploitations d'un bassin cotonnier

Dans une zone soudano-sahélienne, un service d'appui-conseil veut adapter ses conseils aux différents types d'exploitations de son secteur. Il a enquêté auprès de 15 exploitations (\(I=15\)), décrites par cinq variables (\(K=5\)). Le fichier data_stat-0113.xlsx contient, dans la feuille donnees, une ligne par exploitation :

Mode d'emploi
  • Chaque question donne le code R à taper dans un script (à enregistrer dans votre dossier OneDrive : STAT_Nom_Prenom), pas dans la console : on garde ainsi une trace de tout ce que l'on fait. Pour exécuter une ligne, placer le curseur dessus et taper Ctrl + Entrée.
  • Après chaque bloc de code : exécuter le code, comparer la sortie aux lignes ✓ Contrôle, lire les encadrés Lecture, puis répondre aux questions.
  • Tout ce qui suit le signe # est un commentaire : R l'ignore.
  • La numérotation des classes (1, 2, 3) et l'ordre des feuilles du dendrogramme peuvent changer d'un ordinateur à l'autre : c'est la composition des classes qui compte.
  1. Préparer la séance, importer et explorer les données.
    1. Dans votre dossier de travail OneDrive, placer le fichier data_stat-0113.xlsx dans data_raw. Lancer RStudio à partir du fichier _stat_Istom.Rproj. Installer une seule fois les packages utiles au TD : 
      install.packages(c("readxl", "FactoMineR"))  # une seule fois
    2. Importer les données et les résumer : 
      library(readxl)
exploit <- as.data.frame(read_excel("data_raw/data_stat-0113.xlsx", sheet = "donnees"))
rownames(exploit) <- exploit$Exploitation   # noms de lignes = exploitations
exploit$Exploitation <- NULL                # on retire la colonne de noms
str(exploit)                                # structure du tableau
summary(exploit)                            # ordres de grandeur tres differents
round(apply(exploit, 2, sd), 2)             # ecart-type de chaque variable
      ✓
      Contrôlestr affiche 15 obs. of 5 variables ; la moyenne de Rdt_cereales vaut \(937{,}8\) et son écart-type \(141{,}23\).
      Comparez les ordres de grandeur des cinq variables (lignes Min. et Max. de summary, écarts-types). Pourquoi serait-il dangereux de calculer des distances directement sur ces données brutes ?
  2. Centrer et réduire. 
    exploit.cr <- scale(exploit)   # chaque variable : moyenne 0, ecart-type 1
round(head(exploit.cr), 2)
    Lecture

    scale() remplace chaque valeur par son écart à la moyenne divisé par l'écart-type : \(z_{ik} = (x_{ik}-\overline{x}_k)/s_k\). Toutes les variables pèsent alors autant, quelle que soit leur unité : une différence de cheptel et une différence de rendement deviennent comparables.

    ✓
    Contrôlepour Exp01, Cheptel_UBT vaut \(1{,}51\) et Rdt_cereales \(-0{,}66\).
    Retrouver à la main la valeur \(1{,}51\) de Exp01 pour le cheptel (Exp01 a 24 UBT). Comment l'interpréter ?
  3. Construire l'arbre (CAH de Ward). 
    d <- dist(exploit.cr)                     # distances euclidiennes entre exploitations
arbre <- hclust(d, method = "ward.D2")    # CAH, critere de Ward
plot(arbre, hang = -1, main = "Dendrogramme", xlab = "", sub = "")
    Lecture

    dist() calcule les distances entre individus ; hclust(..., "ward.D2") construit l'arbre en fusionnant, à chaque étape, les deux classes dont la réunion fait perdre le moins d'inertie inter-classe. La hauteur d'un branchement mesure le coût de la fusion : plus elle est haute, plus les deux groupes réunis étaient différents.

    1. Combien de grands groupes se dessinent « à l'œil » sur le dendrogramme ? Quelles exploitations les composent ?
  4. Choisir le nombre de classes. 
    round(rev(arbre$height), 2)               # hauteurs, de la derniere fusion a la premiere
barplot(rev(arbre$height),
        names.arg = seq_along(arbre$height),
        xlab = "fusions (de la derniere a la premiere)",
        ylab = "hauteur (perte d'inertie)")
classe <- cutree(arbre, k = 3)            # on decoupe en 3 classes
table(classe)                             # effectif de chaque classe
plot(arbre, hang = -1, main = "", xlab = "", sub = "")
rect.hclust(arbre, k = 3, border = 2:4)   # encadre les 3 classes
    Où couper l'arbre ?

    Le diagramme en barres montre les hauteurs de fusion, de la dernière (la plus coûteuse) à la première. On coupe juste avant un grand saut : le nombre de classes correspond au nombre de branches coupées par la ligne horizontale. Couper sous les \(q-1\) dernières fusions laisse \(q\) classes.

    ✓
    Contrôleles trois premières hauteurs valent \(8{,}80\) ; \(6{,}71\) ; \(2{,}05\).
    1. Le découpage en \(3\) classes est-il cohérent avec le plus grand saut du diagramme ? Donner l'effectif de chaque classe.
    2. Pour aller plus loin. Avec ward.D2, une fusion de hauteur \(h\) fait perdre \(h^2/2\) d'inertie inter-classe, et l'inertie totale des données centrées-réduites vaut \((I-1)\times K\). Calculer la part de l'inertie expliquée (le \(R^2\)) par la partition en trois classes, puis en deux classes.
  5. Caractériser les classes. 
    aggregate(exploit, by = list(classe = classe), FUN = mean)  # moyennes par classe
split(rownames(exploit), classe)                            # composition des classes
    Lecture

    aggregate donne, pour chaque classe, la moyenne de chaque variable. On compare ces moyennes entre classes et à la moyenne générale (ligne Mean de summary) pour décrire chaque groupe et lui donner un nom.

    1. Pour chaque classe, repérer les deux ou trois variables les plus caractéristiques (nettement au-dessus ou en dessous des autres classes).
    2. Proposer un nom agronomique pour chacune des trois classes.
  6. Pour aller plus loin : classification sur composantes et valeurs-tests. 
    library(FactoMineR)
res.pca  <- PCA(exploit, scale.unit = TRUE, graph = FALSE)
res.hcpc <- HCPC(res.pca, nb.clust = 3, graph = FALSE)
plot(res.hcpc, choice = "map")        # les classes sur le plan de l'ACP
res.hcpc$desc.var$quanti              # valeurs-tests : variables qui caracterisent
    La valeur-test

    HCPC fait une CAH de Ward sur les coordonnées de l'ACP, puis consolide la partition par k-means. Pour chaque classe, il trie les variables par valeur-test : une valeur-test positive (resp. négative) et de module \(\ge 1{,}96\) signale une variable significativement plus forte (resp. plus faible) dans la classe que dans l'ensemble. C'est la version automatique de la lecture faite à la question 5.

    1. HCPC retrouve-t-il les mêmes classes qu'à la question 4 ? Pourquoi ?
    2. Les valeurs-tests confirment-elles les noms de classes proposés à la question 5 ?
    3. Rédiger, en trois ou quatre phrases, une synthèse de la typologie obtenue, à l'intention du service d'appui-conseil.

Indications

Exercice 1

  1. Si read_excel ne trouve pas le fichier, vérifier qu'il est bien dans le dossier data_raw, que RStudio a été lancé depuis le fichier .Rproj (getwd() affiche le dossier de travail) et que le chemin s'écrit avec /, jamais avec \. Une distance euclidienne additionne des carrés d'écarts : quelle variable aura les plus grands écarts, simplement à cause de son unité ?
  2. Sur données centrées-réduites, une valeur de \(+1{,}5\) signifie « \(1{,}5\) écart-type au-dessus de la moyenne ».
  3. Repérer les branchements très hauts, puis compter les branches situées juste en dessous.
  4. Le plus grand saut est le plus grand écart entre deux barres successives. Pour le \(R^2\) : additionner les \(h^2/2\) des fusions situées au-dessus de la coupure et diviser par \((15-1)\times5\).
  5. Comparer chaque moyenne de classe à la moyenne générale. Pensez au fonctionnement d'une exploitation : surface, main-d'œuvre, troupeau, destination de la production.
  6. Avec \(K=5\) variables, l'ACP a cinq composantes et PCA les garde toutes par défaut (ncp = 5) : les distances entre individus sont alors exactement celles des données centrées-réduites. Une valeur-test supérieure à \(1{,}96\) en valeur absolue signale une variable significativement différente dans la classe ; le signe dit dans quel sens.

Exercice 2

  1. Comparer les unités : hectares, pourcentages, nombre de cultures, milliers de FCFA. Quelle variable dominerait des distances calculées sur données brutes ?
  2. Reprendre les blocs de code de l'exercice 1 en changeant le nom du fichier et de l'objet.
  3. rev(arbre$height) donne les hauteurs de la dernière fusion à la première : chercher le plus grand écart entre deux valeurs successives. L'inertie totale vaut \((18-1)\times 6\).
  4. Une variable caractérise une classe si sa moyenne y est nettement au-dessus ou au-dessous de la moyenne générale (valeur-test supérieure à \(1{,}96\) en valeur absolue).
  5. Pensez aux contraintes de chaque type : foncier, eau, trésorerie pour les intrants, main-d'œuvre, accès au marché. Une marge par hectare ne dit pas tout du revenu de l'exploitation.
