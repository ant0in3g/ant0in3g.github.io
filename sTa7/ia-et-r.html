IA et R : faire tourner un modèle en local

Un tentative de tutoriel pour installer un modèle de langage (LLM) directement sur votre ordinateur et l'utiliser, par exemple, pour vous aider à écrire du code R, gratuitement, sans compte, et sans envoyer vos données sur un serveur distant.

Pourquoi faire tourner une IA en local ?

Faire tourner un modèle « en local », c'est l'exécuter sur votre propre machine plutôt que sur les serveurs d'une entreprise (comme ChatGPT ou Claude). Les avantages : c'est gratuit, cela fonctionne hors-ligne, vos données restent privées, et c'est une excellente façon de comprendre concrètement comment fonctionnent ces outils. En contrepartie, la qualité dépend de la taille du modèle que votre matériel peut supporter.

Prérequis matériel

Un LLM doit être chargé en mémoire pour produire du texte : la contrainte principale est donc la mémoire disponible. Pour générer des scripts R corrects, visez un modèle d'au moins 3 à 7 milliards de paramètres (noté 3B à 7B).

  • Sans carte graphique : prévoyez environ 7 Go de RAM libres pour un modèle 7B.
  • Avec une carte graphique : il faut qu'elle dispose d'au moins 7 Go de VRAM, et le calcul est bien plus rapide sur GPU.

Repère : un modèle plus petit (0.5B–1.5B) tournera sur presque n'importe quelle machine, mais donnera des résultats plus limités. À vous de trouver le meilleur compromis pour votre ordinateur.

Le tutoriel en 3 étapes

  1. Installer un serveur LLM local

    Ces outils gèrent le téléchargement et l'exécution des modèles, avec une interface de discussion façon ChatGPT. Le plus simple pour commencer est Ollama. Alternatives conviviales : LM Studio et Open WebUI. Téléchargez, installez, c'est prêt.

  2. Télécharger un modèle

    Une fois Ollama installé, ouvrez un terminal et récupérez un modèle spécialisé dans le code. Par exemple :

    ollama pull qwen2.5-coder:3b

    Remplacez 3b par la taille voulue (0.5b, 1.5b, 3b, 7b…) selon votre matériel.

  3. Poser vos questions

    Lancez le modèle et discutez avec lui comme sur un chat classique :

    ollama run qwen2.5-coder:3b

    Vous pouvez alors lui demander, par exemple : « Écris-moi un script R qui charge un fichier CSV, calcule la moyenne par groupe et trace un boxplot. » Relisez et testez toujours le code proposé, un petit modèle peut se tromper.

Quels modèles essayer ?

Pour de l'aide au code R, deux bonnes familles pour débuter :

  • Qwen2.5-Coder, décliné en plusieurs tailles (0.5B, 1.5B, 3B, 7B et plus). Les résultats commencent souvent à devenir intéressants à partir de 3B, mais c'est à tester.
  • Mistral, les modèles de l'éditeur français, également disponibles via Ollama et LM Studio.

Conseil : commencez petit, jugez la qualité des réponses, puis montez en taille si votre machine suit.

Un regard critique : le coût écologique de l'IA

Utiliser ces outils, en local ou dans le cloud, n'est pas neutre : entraînement et usage des grands modèles consomment énormément d'énergie, d'eau et émettent du CO₂. Quelques lectures pour garder l'esprit critique :
