Organisation pratique

Dossier OneDrive

Afin de faciliter notre travail en travaux dirigés, je vous partage un dossier OneDrive.

Il vous est demandé de synchroniser ce dossier OneDrive sur votre ordinateur personnel.

Étapes de synchronisation d'un dossier partagé OneDrive (Windows/Mac)

  1. Vérifier OneDrive sur son PC — bouton Démarrer, taper OneDrive ; s'il n'est pas installé, le télécharger depuis Microsoft ; se connecter avec son compte Microsoft ISTOM.
  2. Accéder au dossier partagé — se connecter sur onedrive.live.com, menu de gauche → Partagé, trouver le dossier à synchroniser.
  3. Synchroniser le dossier — ouvrir le dossier partagé, cliquer sur Synchroniser ; l'application OneDrive se lance et confirme la synchronisation.
  4. Retrouver le dossier — Explorateur de fichiers (Windows + E) → rubrique ISTOM.

Usage sur un ordinateur de l'école

Sur un ordinateur de l'école, il est plus pratique de créer un raccourci du dossier partagé sur votre OneDrive ISTOM. La démarche est expliquée dans cette vidéo.

Tutoriel R & RStudio

R est un langage de programmation et un environnement statistique open-source, largement utilisé pour l'analyse de données, les statistiques et la science des données. Créé dans les années 1990 par Ross Ihaka et Robert Gentleman, il est apprécié pour le traitement des données, la modélisation statistique et la visualisation. Grâce à une vaste communauté, R bénéficie d'un large écosystème de packages (via CRAN).

RStudio est un environnement de développement intégré (IDE) qui facilite l'utilisation de R : éditeur avancé, console interactive, outils de visualisation, gestion de projets, intégration Git, et génération de rapports dynamiques avec R Markdown et Quarto.

  • R Markdown : format de document intégrant du code R pour générer des rapports dynamiques (HTML, PDF, Word…).
  • Quarto : évolution de R Markdown, multi-langage (R, Python, Julia…), pour documents scientifiques, tableaux de bord et sites web.

Pour installer R et RStudio il faut un PC Windows, une distribution Linux (par ex. Ubuntu) ou un Mac. On trouve des ordinateurs de qualité à moindre prix, en reconditionné, par exemple sur Back Market.

Installation de R

Rendez-vous sur le site officiel CRAN pour télécharger et installer R (choisir sa plateforme). Sous Windows, cliquez sur install R for the first time puis installez également Rtools, ou via R :

install.packages("utils")
install.packages("installr")
installr::install.Rtools()

Installation de RStudio

En programmation, un IDE (environnement de développement) est un ensemble d'outils qui augmente la productivité des programmeurs. Source : Wikipédia

Téléchargez RStudio depuis Posit, en choisissant l'installateur associé à votre système.

Configuration de RStudio

À la première ouverture, votre écran doit ressembler à ceci.

L'organisation est modulable dans Tools > Global options. Commençons par le Pane Layout (Tools > Global options > Pane Layout).

  • En haut à gauche : la fenêtre Source (les scripts).
  • En haut à droite : Environnement, History, Connections, Build, VCS, Tutorial.
  • En bas à gauche : la Console (Terminal, Background Jobs).
  • En bas à droite : Files, Plots, Packages, Help, Viewer, Presentations.

R General (Tools > Global options > R General) :

  • Vérifiez la version R (bouton Change).
  • Workspace : décocher Restore .RData… et choisir Never pour Save workspace….
  • History : laisser décochés. Other : laisser cochés les trois premiers.

Code / Editing : sélectionnez Use native pipe operator.

Code / Display : sélectionnez Use rainbow parentheses.

Appearance : à vous de choisir les options qui vous conviennent.

RappelNe pas oublier de cliquer sur Apply ! Pour vérifier votre version : sessionInfo().

Les projets avec RStudio

Un projet centralise les éléments de travail (données, scripts, documentation, images) dans un dossier et évite les interactions involontaires entre projets.

Maintenir les packages à jourOnglet Packages → Update, ou Tools > Check for Package Update. À faire au moins une fois par mois.

À la création, le dossier ne contient que le fichier .Rproj. Il est conseillé de créer des sous-dossiers : data_raw, data, doc, img.

Script R

Créez un script (File > New File > R Script), enregistrez-le, puis écrivez votre première ligne :

2 + 3

Enregistrez et cliquez sur Run.

Script Quarto

Quarto est la nouvelle génération de R Markdown : documents (HTML, Word, PDF), diapositives, dashboards, sites web, livres — nativement. Quelques éléments de syntaxe :

  • Saut de ligne : double espace en fin de ligne.
  • *italique*, **gras**, ***gras et italique***, ~~raturé~~.
  • Code : `code`. Titres : #, ##, ###…

Syntaxe complète sur la page Quarto. Créez un document (File > New File > Quarto Document).

Vous aurez besoin du package rmarkdown (cadran Packages → Install).

Pour générer le HTML, cliquez sur Render (ou Ctrl + Shift + K). Un ensemble d'exemples de ce qu'il est possible de faire avec Quarto.

Les différents types de données

numeric, integer (1L), complex (9 + 3i), character, logical. On vérifie avec class().

x <- 10.5;     class(x)   # numeric
x <- 1000L;    class(x)   # integer
x <- 9i + 3;   class(x)   # complex
x <- "R is exciting"; class(x)   # character
x <- TRUE;     class(x)   # logical

Objets : vecteurs, listes, matrices, data frames, facteurs.

x <- c(55, 1, 2, 3, 4)
length(x); sort(x); x[3]

ma_liste <- list("apple", "banana", "cherry")
"apple" %in% ma_liste

mat <- matrix(1:9, nrow = 3, ncol = 3)
mat[1,2]; mat[,2]; dim(mat)

df <- data.frame(Age = c(25, 30, 35), Sexe = c('Homme','Femme','Homme'))
summary(df)

music_genre <- factor(c("Jazz","Rock","Classic","Pop"))
levels(music_genre)

Conditions, boucles

# If ... Else
a <- 200; b <- 33
if (b > a) { print("b is greater than a") }
else if (a == b) { print("a and b are equal") }
else { print("a is greater than b") }

# AND / OR
if (a > b & c > a) { print("Both conditions are true") }
if (a > b | a > c) { print("At least one is true") }

# While
i <- 1
while (i < 6) { print(i); i <- i + 1 }

# For
fruits <- list("apple", "banana", "cherry")
for (x in fruits) { print(x) }
